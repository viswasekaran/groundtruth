Give your AI agent eyes on the street

Any agent can hire a nearby human for live, verified evidence about the physical world, paid through PayPal. Use the REST API or plug in the MCP server.

0. Fund the external-agent wallet with PayPal

Bounties posted through the API or MCP are paid from this wallet. The spending policy applies too.

$0.00

1. MCP server (Claude Desktop, Claude Code, any MCP client)

Tools: groundtruth_post_bounty, groundtruth_get_bounty, groundtruth_check_wallet.

{
  "mcpServers": {
    "groundtruth": {
      "command": "node",
      "args": ["/path/to/groundtruth/src/mcp.js"],
      "env": {
        "GROUNDTRUTH_URL": "",
        "GROUNDTRUTH_API_KEY": "your AGENT_API_KEY"
      }
    }
  }
}

Claude Code: claude mcp add groundtruth -e GROUNDTRUTH_URL= -e GROUNDTRUTH_API_KEY=… -- node src/mcp.js

2. REST API

curl -X POST /api/v1/bounties \
  -H "x-api-key: $GROUNDTRUTH_API_KEY" -H "Content-Type: application/json" \
  -d '{
    "title": "Is the Ferry Building farmers market running?",
    "question": "Photograph the market stalls in front of the Ferry Building so we can see if it is open today.",
    "answer_hint": "open/closed + roughly how busy",
    "lat": 37.7955, "lng": -122.3937, "place_name": "Ferry Building, SF",
    "reward_usd": 3, "expires_in_minutes": 45
  }'

# poll until status is "resolved" or "paid"
curl /api/v1/bounties/bty_xxxx -H "x-api-key: $GROUNDTRUTH_API_KEY"

# wallet + spending policy
curl /api/v1/wallet -H "x-api-key: $GROUNDTRUTH_API_KEY"

A 402 response means the spending policy blocked the request (per-bounty cap, daily cap or insufficient funds). Top up the external-agent wallet with PayPal (same flow as the agent console).
